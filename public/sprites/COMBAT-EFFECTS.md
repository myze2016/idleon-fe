# Painted combat effects

`combat-effects-v1.png`, generated with the built-in imagegen tool using the dual-knife art as reference. Shared by expedition and PvP combat. Code animates travel, slash rotation, impact growth, support pulses and fading; combat timing and damage stay unchanged. Procedural effects remain loading fallbacks.

Atlas rows: sword slash, dagger slash, impact, muzzle flash; arrow, bullet, magic orb, fireball; ice, healing, buff, shield.

## Prompt

Simple hand-painted anime RPG combat EFFECTS sprite atlas, true transparent background, 4 columns x3 rows equal square cells, landscape1536x1152. Same clean painted art style as reference. Each effect centered and isolated with generous margins, no characters, text, background or UI. Exact row-major order: silver crescent sword slash; crossed violet dagger slash; orange impact spark burst; golden muzzle flash. Row2: wooden arrow pointing RIGHT; small gold bullet tracer pointing RIGHT; blue magic orb with short trail pointing RIGHT; orange fireball with short trail pointing RIGHT. Row3: ice crystal burst; green healing sparkle and plus; violet buff magic ring; pale blue shield impact. Low detail, readable shapes, soft glow only near effect, no huge haze. Production game effect sprites, not framed icons.
