# Generated parchment

`parchment-panel-v1.png`, generated with the built-in imagegen tool using the cabin as an art-style reference. Shared by HUD info boxes, map labels, and menu panels. Canvas uses nine-slice rendering to preserve corners; DOM menu cards use CSS border images. Text stays rendered separately.

## Prompt

ONE reusable square fantasy RPG parchment UI panel asset 1024x1024, opaque full-bleed. Same hand-painted anime adventure style as reference cabin. Warm cream paper center, soft fibrous grain, worn caramel brown edges, thin hand-inked border inset 6%, tiny simple leaf flourishes ONLY at four corners. Very spacious blank center for readable game text. Subtle creases and a few faded speckles, modest detail, no lavish gold, no screws, no words, no icons, no letters, no shadows outside asset. All four edges straight for nine-slice resizing, ornaments confined to outer 12%. No background scene. Production UI texture for info boxes and menu windows.
