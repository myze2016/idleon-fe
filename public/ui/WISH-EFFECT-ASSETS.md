# Wish and enhancement effects

`summon-seal-v1.png` was generated with the built-in imagegen tool for this project. It is a transparent painted gold/cyan summoning seal with an open center. Wish effects animate its rotation, particles and reveal in canvas; special wishes tint it violet. Artifact enhancement reuses the seal for a brief success burst, spark particles and a rising enhancement level.

The animations respect `prefers-reduced-motion`. Missing images fall back to drawn wish rings. Effects do not determine rewards or upgrade success; the existing API remains authoritative.
