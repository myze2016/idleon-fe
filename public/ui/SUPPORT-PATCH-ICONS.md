# Support and Patch Notes toolbar icons

Generated with the built-in imagegen tool, using `adventure-button-icons-v2.png` as the art reference. These are separate transparent PNGs, rendered by the shared RPG toolbar button renderer with the same glow and text treatment as the original atlas.

- `support-icon-v1.png`: ruby heart, golden supporting palm, and coins.
- `patch-notes-icon-v1.png`: announcement scroll, golden quill, and emerald seal.

The toolbar wraps and adjusts row height to keep its eleven buttons clear of the bottom room HUD on narrow screens.
